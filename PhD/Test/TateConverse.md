# The converse: from `IsTateRing` back to `IsTate`

Status: **not started, and not currently recommended.** This note records what the converse
statement would have to be, what it would cost, and what it would and would not buy — so the
decision can be revisited without re-deriving any of it.

Written 2026-07-31, against [`TateRings.lean`](../TateFredholm/HandClean/TateRings.lean) as it stands.

## 1. Where we are

[`TateRings.lean`](../TateFredholm/HandClean/TateRings.lean) proves one direction:

```lean
theorem isTateRing_of_isTate (A : Type*) [NormedCommRing A] [NormOneClass A]
    [IsUltrametricDist A] [IsTate A] : IsTateRing A
```

via `PseudoUniformizer.pairOfDefinition`, whose ring of definition is the closed unit ball
`A⁰ = {a | ‖a‖ ≤ 1}` (`unitBall`) and whose ideal of definition is `(ϖ)`. The load-bearing
lemma is `mem_ideal_pow`: `(ϖ)ⁿ = {a ∈ A⁰ | ‖a‖ ≤ ‖ϖ‖ⁿ}`, i.e. the ideal powers *are* the norm
balls, which is what makes the `(ϖ)`-adic and subspace topologies literally coincide rather than
merely compare. `exists_pow_mul_mem_unitBall` gives `A = A⁰[1/ϖ]`.

So: every `IsTate` ring is a Tate ring in Wedhorn's sense (Definitions 6.1, 6.10, quoted verbatim
in the file). That is the claim `IsTate` is *a legitimate* formalisation. It is not yet the claim
that it is *the* formalisation.

## 2. Why the converse cannot be `IsTateRing A → IsTate A`

`IsTate A` presupposes `[NormedRing A]`. A norm is **data**; a Huber ring carries only a topology.
There is no implication to state — the converse has to assert the *existence* of a compatible
norm.

Proposed statement:

```lean
theorem IsTateRing.exists_isTate_norm (A : Type*) [CommRing A] [TopologicalSpace A]
    [IsTateRing A] [T0Space A] [Nontrivial A] :
    ∃ (f : A → ℝ) (ϖ : Aˣ),
      -- f is an ultrametric submultiplicative ring norm with f 1 = 1
      (∀ a, f a = 0 ↔ a = 0) ∧ (∀ a b, f (a + b) ≤ max (f a) (f b)) ∧
      (∀ a b, f (a * b) ≤ f a * f b) ∧ (∀ a, f (-a) = f a) ∧ f 1 = 1 ∧
      -- ϖ is a multiplicative pseudo-uniformizer for f
      f ϖ < 1 ∧ (∀ x, f (ϖ * x) = f ϖ * f x) ∧
      -- and f induces the given topology
      (𝓝 (0 : A)).HasBasis (fun ε : ℝ ↦ 0 < ε) fun ε ↦ {a | f a < ε}
```

The final clause is what makes this a converse rather than "some unrelated norm exists". Stating
it as a `HasBasis` at `0` (rather than as an equality of `TopologicalSpace` instances) keeps the
statement free of `@`-annotations and matches the shape of `PairOfDefinition.hasBasis_nhds_zero`.

Two hypotheses are forced and cannot be dropped:

- **`[T0Space A]`** — without separatedness the construction yields only a *semi*norm
  (`⋂ₙ πⁿA₀ = closure {0}`). For topological groups T0 ⇒ T2, so this is the weakest form.
- **`[Nontrivial A]`** — otherwise `f 1 = 1` fails. Same edge case as `PseudoUniformizer.norm_pos`
  in `TateRings.lean`.

### Packaging options

The `∃ f : A → ℝ` form above is the recommended primary statement: explicit, readable, no
instance gymnastics. If a version that literally produces `IsTate` is wanted later, the clean
route is a type synonym

```lean
def WithGaugeNorm (A : Type*) [CommRing A] [TopologicalSpace A] := A
```

carrying `NormedCommRing` / `NormOneClass` / `IsUltrametricDist` / `IsTate` instances, together
with a `RingEquiv A (WithGaugeNorm A)` that is a `Homeomorph`. That is pure packaging on top of
the existence theorem, and should not be attempted before it.

## 3. What the Huber side supplies — 162 lines, verified

The construction runs off **Wedhorn 6.14**: a Tate ring admits a pair of definition whose ideal is
principal, generated by a *unit* of `A`. In the supervisor's `HuberRings.lean` this is
`IsTateRing.exists_principal_pairOfDefinition`. Principality-by-a-unit is exactly what later makes
`f (ϖ x) = f ϖ · f x` an equality rather than an inequality.

Its dependency closure was extracted and compiled appended to the current `TateRings.lean`:
**162 lines, 0 errors, 0 warnings, 0 sorries, standard axioms only, and no imports beyond the
seven `TateRings.lean` already has.**

## 4. What is genuinely new — the gauge norm

Given a principal pair `(A₀, (π))` with `π ∈ Aˣ`, define `‖a‖ = (1/2)^{v(a)}` where
`v(a) = sup {n : ℤ | a ∈ πⁿ·A₀}`. Ordered by dependency, with rough sizes:

1. **`A = A₀[1/π]`** — `∀ a, ∃ m : ℕ, πᵐ a ∈ A₀`. From `π` topologically nilpotent, `A₀` open,
   and continuity of `· * a`. Makes `{n | a ∈ πⁿA₀}` nonempty. *(~10 lines)*
2. **`⋂ₙ πⁿA₀ = {0}`** — from `hasBasis_nhds_zero` plus `closure {0} = {0}` under T0. Makes the
   set bounded above for `a ≠ 0`. *(~15 lines)*
3. **`gaugeVal : A → ℤ`**, characterised by `n ≤ v a ↔ a ∈ πⁿ·A₀`. The set is downward closed
   (`πⁿA₀ ⊆ πⁿ⁻¹A₀`), nonempty by (1) and bounded above by (2), so `Int.exists_greatest_of_bdd`
   applies. This is the fiddliest step — mostly `zpow` bookkeeping on the `Aˣ`-orbit of `A₀`.
   *(~60–80 lines)*
4. **The norm axioms.** Each falls straight out of the corresponding filtration fact:
   - ultrametric ← `πⁿA₀` is an additive subgroup;
   - submultiplicative ← `A₀ · A₀ ⊆ A₀`;
   - `‖a‖ = 0 ↔ a = 0` ← (2);
   - `‖1‖ = 1` ← `1 ∉ πA₀` (this is where `Nontrivial` is spent);
   - `v(π x) = v(x) + 1`, hence `‖π x‖ = ‖π‖‖x‖` and `‖π‖ = 1/2 < 1` ← **`π ∈ Aˣ`**.
   *(~80 lines)*
5. **`{a | ‖a‖ ≤ (1/2)ⁿ} = πⁿ·A₀`**, hence the `HasBasis` clause. This is the mirror image of
   `mem_ideal_pow` in `TateRings.lean`. *(~30 lines)*

Estimate: **250–350 new lines**, on top of the 162 recovered — call it **400–500 total**. The
mathematics is standard and has no known obstruction; step 3 is where the Lean friction is.

## 5. What the converse would and would not settle

**It would not make the round trip an identity.** The gauge norm has value group `(1/2)^ℤ`, so
`IsTate → IsTateRing → IsTate` returns the same *topology* but in general a different, merely
**equivalent** norm. The correct form of "`IsTate` is the right formalisation" is therefore:

> the two notions agree **up to equivalence of norms**.

That is exactly why [JN] Lemmas 2.1.6–2.1.7 and Proposition 2.1.8 exist, and why
`norm_le_pow_of_equiv`, `norm_comparison_of_common_uniformizer`,
`isCompletelyContinuous_map_equiv` and `charPowerSeries_map_equiv` are in
[`BaseChange.lean`](../TateFredholm/BaseChange.lean). **The converse alone does not close the argument** —
it is the converse *plus* those invariance lemmas. Since the invariance lemmas are already proved,
the marginal value of the converse is the statement, not the theory.

Two further notes:

- The gauge norm is submultiplicative but **not** `NormMulClass`, so `A⁰ ⊊ A°` can persist. This
  is consistent with the discussion in the `TateRings.lean` header: `A°` is a ring of definition only
  when `A` is uniform.
- Nothing in `PhD/TateFredholm/` consumes `IsTateRing`. The converse is a foundational
  justification, not an enabler of downstream work.

## 6. Recommendation

Defer. The forward direction plus the norm-equivalence lemmas already in `BaseChange.lean` carry
the mathematical content; the converse is a 400–500 line addition whose payoff is the ability to
state a biconditional. Reasonable triggers for revisiting:

- a referee or examiner asks for the biconditional explicitly;
- `IsTateRing` acquires a downstream consumer, so that transporting results across the
  correspondence becomes useful rather than decorative;
- the gauge norm turns out to be wanted independently (it is the natural `ForMathlib` route to
  "every separated Tate ring is normable", which is a genuine gap in Mathlib).

If it is revisited, do it in this order: recover the 162 lines (verified, mechanical) → steps 1–2
(cheap, and independently useful) → step 3 (the real work) → steps 4–5 → packaging.
