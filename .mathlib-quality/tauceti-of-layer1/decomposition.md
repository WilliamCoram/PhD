## §1.1 Level monoids in norm form (`Level.lean`, `Dictionary.lean`)

### Plain-English proof substrate

[Buz07, §9, p. 68] (`buzzard.txt:2638`): "define `M_t` to be the elements `(γ_j)` of `M₂(𝒪_p)` with
the property that if `γ_j = ((a_j b_j), (c_j d_j))` then `det(γ_j) ≠ 0`, `π_j^{t_j}` divides `c_j`, and
`π_j` does not divide `d_j`. Then `M_t` is a monoid under multiplication." [Jac03, Definition 1.27,
p. 19] (`jacobs_thesis.txt`, page 19; `Σ_α`, `∣`, `∤` restored): "Given `α ∈ ℕ`, let
`Σ_α = {γ = ((a b), (c d)) ∈ M₂(ℤ_p) : p^α ∣ c, p ∤ d, det(γ) ≠ 0}`. […] It is an easy check that `Σ_α`
is a monoid."

*The monoid law.* For `g = ((a b), (c d))`, `h = ((a' b'), (c' d'))` with integral entries, `‖c‖, ‖c'‖ ≤ ρ`,
`‖d‖ = ‖d'‖ = 1`: the product has entries `Σ_k g_{ik} h_{kj}`, integral by the ultrametric inequality;
lower-left `c a' + d c'`, with `‖c a'‖ ≤ ρ` and `‖d c'‖ ≤ ρ`; lower-right `c b' + d d'`, with
`‖c b'‖ ≤ ρ < 1 = ‖d d'‖`, so of norm exactly `1` by the isosceles principle
(`IsUltrametricDist.norm_add_eq_max_of_norm_ne_norm`); `det (gh) = det g det h ≠ 0`. The identity has
`c = 0` (needs `0 ≤ ρ`) and `d = 1`.

*The determinant bound* ([RM] §1.1.2): `a d = det γ + b c` (`Matrix.det_fin_two`), `‖d‖ = 1`,
`‖b c‖ ≤ ρ ≤ σ`, so `‖a‖ = ‖a d‖ ≤ max(‖det γ‖, ‖bc‖) ≤ σ`. [Buz07, proof of Lemma 12.2] is the
application (`det((x_δ)_p)/det(η_p)` is a unit).

*Units.* If `g` is a unit of `Σ(ρ)` with inverse `h`, `det g · det h = 1` with both norms `≤ 1`, so
`‖det g‖ = 1`. Conversely, if `‖det g‖ = 1`, the inverse `adj(g)/det g = ((d −b), (−c a))/det g` has
integral entries, lower-left `‖−c/det g‖ = ‖c‖ ≤ ρ`, lower-right `‖a/det g‖ = ‖a‖`, and `‖a‖ = 1`
because `ad = det g + bc` with `‖bc‖ ≤ ρ < 1 = ‖det g‖`. `η = diag(ϖ, 1)` has `det η = ϖ`, so it is a
unit iff `‖ϖ‖ = 1`.

*`Σ₁`-type levels* ([RM] §1.1.3): `(gh)_{10} = c a' + d c'` with `‖c a'‖ ≤ ρ²`, `‖d c'‖ ≤ ρ²`;
`(gh)_{11} − 1 = c b' + (d d' − 1) = c b' + d (d' − 1) + (d − 1)`, each term of norm `≤ ρ`.

*The adjugate dictionary* ([RM] §1.1.4; convention 2): `adj ((a b), (c d)) = ((d −b), (−c a))`
(`Matrix.adjugate_fin_two`), `adj (gh) = adj h · adj g` (`Matrix.adjugate_mul_distrib`),
`det (adj g) = det g` (`Matrix.det_adjugate` at `card − 1 = 1`), `adj (adj g) = g`
(`Matrix.adjugate_adjugate` at `card − 2 = 0`). Under `adj`, `‖d‖ = 1` becomes `‖a‖ = 1` and
`‖c‖ ≤ ρ` becomes `‖−c‖ ≤ ρ`: `Σ(ρ) ↔ Σ₀(ρ)`. The anti-homomorphism is a monoid isomorphism from
the opposite monoid.

*The dictionary with Layer 0* ([RM] §1.1.1, §1.1.3): [L0] `LocalLevel.mem_monoidM_iff_norm` already
states `g ∈ monoidM K (v ϖ ^ t) ↔ (∀ i j, ‖g i j‖ ≤ 1) ∧ ‖g 1 0‖ ≤ ‖ϖ‖^t ∧ ‖g 1 1‖ = 1 ∧ g.det ≠ 0` for the
normed field `Valued.toNormedField`; the right-hand side is `mem_sigmaNorm_iff`. The Iwahori group
lies in `M(γ)` ([L0] `coe_mem_monoidM`). For `Iw₁(ϖ^{2t})`: `v(c) ≤ v(ϖ)^{2t}` and `v(d − 1) ≤ v(ϖ)^{2t}`
read as `‖c‖ ≤ (‖ϖ‖^t)²` and `‖d − 1‖ ≤ ‖ϖ‖^{2t} ≤ ‖ϖ‖^t` (`Valued.toNormedField.norm_le_iff`).

## §1.2.1, §1.2.4 (bounds) Möbius series (`Mobius.lean`)

### Plain-English proof substrate

[Buz07, Lemma 8.1, p. 59] (`buzzard.txt:2222–2241`): "Let `γ = ((a b), (c d))` be an element of
`M₂(𝒪)` with `|c| < 1`, `|d| = 1` and `det(γ) ≠ 0`. […] (a) There is a map of rigid spaces
`B_r → B^×_{r|π^t|}` which on points sends `(z_i)` to `(c_i z_i + d_i)` […]. (b) There is a map of rigid
spaces `B_r → B_{rm}` which on points sends `(z_i)` to `((a_i z_i + b_i)/(c_i z_i + d_i))`. Proof. (a) […]
let `(z_i)` be an `L`-point of `B_r`. Then there exists `α ∈ 𝒪` such that `|z_i − α_i| ≤ r ≤ 1` for all
`i ∈ I`. In particular `|z_i| ≤ 1` so `|c_i z_i + d_i| = 1`, and so `c_i z_i + d_i` is invertible."
[RM] §1.2 preamble: "`L_{γ,i}^{-1} = d_i^{-1} ∑_m (−c_i/d_i)^m z_i^m` is a restricted series with
`‖coeff_m‖ ≤ ‖c‖^m` because `‖d‖ = 1 > ‖c‖`."

*The inverse.* `L = d (1 − u)` with `u = −(c/d) z_i`, `‖u‖ = ‖c‖ < 1`; `(1 − u)⁻¹ = ∑ u^m` converges in
the Banach algebra `K⟨z⟩` (`NormedRing.inverse_one_sub`, `tsum_geometric_of_norm_lt_one`), and
`u^m = (−c/d)^m z_i^m` is the monomial `monomial (single i m) ((−c/d)^m)`. So `linInv = d⁻¹ ∑ u^m`
is the series with the stated coefficients, `lin · linInv = d(1 − u) · d⁻¹ (1 − u)⁻¹ = 1`, and
`‖coeff_{m e_i} linInv‖ = ‖c‖^m ≤ ρ^m ≤ σ^m`.

*Möbius composition* ([RM] §1.2.1): "`L_{δγ} = L_γ · (L_δ ∘ w_γ)` and `w_{δγ} = w_δ ∘ w_γ` for
`γ, δ ∈ Σ`, as identities of restricted series, the substitution being that of the
`p`-adic-functional-analysis roadmap's §4.1.4". Compute in `K⟨z⟩`, where `L_γ` is a unit:
`L_γ · (L_δ ∘ w_γ) = L_γ · (C c' · N_γ L_γ^{-1} + C d') = C c' · N_γ + C d' · L_γ`, whose coefficients are
`c' b + d' d` (constant) and `c' a + d' c` (in `z_i`) — the lower row of `δγ` (`Matrix.mul_apply`,
`Fin.sum_univ_two`). Likewise `N_{δγ} = L_γ · (N_δ ∘ w_γ)`. Then
`w_{δγ} = N_{δγ} L_{δγ}^{-1} = (N_δ ∘ w_γ)(L_δ ∘ w_γ)^{-1} = (N_δ L_δ^{-1}) ∘ w_γ` because the
substitution is a ring homomorphism and sends `Ring.inverse` of a unit to `Ring.inverse` of its
image (`Ring.inverse_map`-type reasoning, or `mul_eq_one` transported). The identity
`f ∘ w_{δγ} = (f ∘ w_δ) ∘ w_γ` follows for `f = X_i` and hence for all `f` by uniqueness of
continuous algebra homomorphisms out of the Tate algebra ([RAG] `algHom_ext_of_continuous`).

*The pointwise formula* ([RM] §1.2.5): `aeval x` is a ring homomorphism with `aeval x (X_i) = x_i`,
`aeval x (C a) = a`; `aeval x (linInv) = (aeval x lin)⁻¹` because `lin · linInv = 1`; so
`aeval x (w_i) = (a x_i + b)/(c x_i + d)`.

*Row bounds* ([RM] §1.2.4): "`‖coeff_l w_{γ,i}‖ ≤ σ^l` for `l ≥ 1` (from `‖c‖ ≤ ρ ≤ σ` and `‖a‖ ≤ σ`),
products of series with this property have it, and `‖coeff_m col‖ ≤ ρ^{|m|} ≤ σ^{|m|}` (Jacobs,
Proposition 2.6 and Lemma 2.7's computation)." Products: `coeff_t (fg) = ∑_{(t₁,t₂) ∈ antidiag t}
f_{t₁} g_{t₂}` ([Mathlib] `MvPowerSeries.coeff_mul`), each term `≤ σ^{|t₁|} σ^{|t₂|} = σ^{|t|}`
(`Finsupp.degree` is additive), and the ultrametric inequality for finite sums. `w_i = N_i · linInv_i`
with `N_i = b + a z_i`: `‖b‖ ≤ 1 = σ^0`, `‖a‖ ≤ σ = σ^1` ✓, and `linInv_i` has `‖coeff_{m e_i}‖ = ‖c‖^m ≤ σ^m`.

## §1.2.3 API gap AG1: the identity theorem (`Identity.lean`)

### Plain-English proof substrate

[RM] §1.2.3: "a series in `K⟨z_i : i ∈ I_𝔭⟩` vanishing at every point `(i(z))_i`, `z ∈ 𝒪`, is zero.
Proof: for a `ℤ_p`-basis `e_1, …, e_d` of `𝒪` the `d × d` matrix `(i(e_β))_{i, β}` is invertible (linear

not needed — the linear substitution `z ↦ M w` with integral `M` is a contractive substitution, and
the way back uses Cramer's rule on *points*, not an inverse substitution; (ii) "`ℤ_p`-basis" becomes
"integral basis with invertible embedding matrix", and `ℤ_p^d` becomes `ℕ^d` (infinite in `𝒪_K`
because `[CharZero K]`).

([RAG] `IsUnit.isNormMulUnit` ✓, `NormMulClass K`); the Gauss norm is attained at `k₀` and strictly
dominates later terms — `IsMulDistinguished 1 f k₀`. [RAG]
`weierstrassPreparation_exists_of_isMulDistinguished` ✓ gives `f = e · ω` with `ω` monic of degree
`k₀` and `e` a (norm-multiplicative) unit. For `‖x‖ ≤ 1`, `aeval x` is a ring homomorphism ([RAG]

(`e(x) e⁻¹(x) = 1`). Hence `{x ∈ Z | f(x) = 0} ⊆ roots(ω)`, finite (`Polynomial.eq_zero_of_infinite_isRoot`

## §1.3.2–§1.3.3 (`Classical.lean`)

### Plain-English proof substrate

[Buz07, §9, p. 68] (`buzzard.txt:2626–2656`, quoted in the module docstring): `L_n` with basis the
monomials `∏ Z_i^{m_i}`, `0 ≤ m_i ≤ n_i`; the right `M_1`-module `L_{n,v}`; "the same definition gives
an action of `GL₂(F_p)` on `L_{n,v}`." [Buz07, §11, p. 73]: "there is a natural injection
`L_{n,v} → A_{κ,r} = 𝒪(B_r)` induced from the natural inclusion `B_r ⊂ (𝔸¹)^I` and one checks easily
that this is an `M_1`-equivariant inclusion."

*The homogeneous model.* `SymPow n` is the `n`-weighted-homogeneous submodule for the weight
`(i, _) ↦ Pi.single i 1` — the span of the monomials `∏ X_{(i,0)}^{m_i} X_{(i,1)}^{n_i − m_i}`
(`weightedHomogeneousSubmodule_eq_finsupp_supported`: supported on `{d | weight w d = n}`, and
`weight w d = (i ↦ d(i,0) + d(i,1))`). `symAct γ := aeval (X_{(i,j)} ↦ ∑_k γ_{i,jk} X_{(i,k)})`;
`aeval g ∘ aeval f = aeval (aeval g ∘ f)` (`MvPolynomial.aeval_comp`-type / `MvPolynomial.algHom_ext`),
and `aeval (symVars γ) (symVars δ v) = ∑_k δ_{jk} ∑_l γ_{kl} X_l = symVars (δγ) v` — so `symAct γ ∘ symAct δ
= symAct (δγ)`: a right action. Weighted homogeneity is preserved by `aeval` of homogeneous
substitutions (induction on `P` via monomials: `aeval f (monomial d r) = r ∏ (f s)^{d s}`, products of
homogeneous are homogeneous of the summed weights — `weightedHomogeneousSubmodule_mul`).

*Dimension.* `SymPow n ≃ (supported on {d | weight d = n}) ≃ ({d // weight d = n} →₀ K)`
(`Finsupp.supportedEquivFinsupp`), and `{d : ι × Fin 2 →₀ ℕ | d(i,0) + d(i,1) = n_i ∀ i} ≃ Π i, Fin (n_i + 1)`
(choose `d(i,0) ≤ n_i`), of cardinality `∏ (n_i + 1)` (`Fintype.card_pi`, `Fintype.card_fin`).

*Dehomogenisation and the bridge.* `toTate (monomial d a) = a ∏_i z_i^{d(i,0)} 1^{d(i,1)} = monomial
(i ↦ d(i,0)) a`; on `SymPow n` the exponent `m = (d(i,0))_i` ranges over `m ≤ n` bijectively (with
`d(i,1) = n_i − m_i`), so `toTate` maps the monomial basis of `SymPow n` bijectively onto the monomials
`z^m`, `m ≤ n`, which are linearly independent in the Tate algebra (coefficients) — injective, image
`polySubmodule n`. Scaling: for `d` with `weight d = n`, `∏_v (λ_{v.1} g_v)^{d_v} = ∏_i λ_i^{d(i,0) +
d(i,1)} ∏_v g_v^{d_v} = ∏_i λ_i^{n_i} ∏_v g_v^{d_v}`. Bridge: `toTate (symAct γ P) = aeval (toTate ∘
symVars γ) P` with `toTate (symVars γ (i,0)) = a_i z_i + b_i = num_i`, `toTate (symVars γ (i,1)) = c_i z_i +
d_i = lin_i`; and `kappaSlash (algWeight n 1) γ (toTate P) = algCol n (c, d) · aeval (mobius) (aeval
(dehom) P) = ∏ lin_i^{n_i} · aeval (fun v => if v.2 = 0 then w_i else 1) P`; by the scaling identity
with `λ_i = lin_i`, `g_{(i,0)} = w_i = num_i linInv_i`, `g_{(i,1)} = 1`: `∏ lin_i^{n_i} aeval g P = aeval
(lin_{v.1} g_v) P = aeval (num_i, lin_i) P` since `lin_i · num_i linInv_i = num_i` ✓. Equal.
