(p. 259) "Alternatively, Tₙ can be viewed as an algebra of functions on Max Tₙ, the set of all
maximal ideals in Tₙ (cf. (3.8)). Recall that, for f ∈ Tₙ and 𝔪 ∈ Max Tₙ, one defines f(𝔪) as the
residue class of f in Tₙ/𝔪. Since Tₙ/𝔪 is a finite algebraic extension of k, it can be embedded as
a subfield of k_a, and thus f(𝔪) can be viewed as an element of k_a. However, the embedding of Tₙ/𝔪
into k_a is not, in general, unique. […] Note also that Γ acts isometrically on k_a. Hence |f(𝔪)| is
a well-defined real number, and we have |f(𝔪)| = 0, if and only if f(𝔪) = 0, i.e., f ∈ 𝔪."

(p. 260) "For x ∈ Bⁿ(k_a), denote by 𝔪_x the ideal of all f ∈ Tₙ vanishing at x. Let k(x) be the
finite algebraic extension field of k generated by all components of x. Then, considering the
epimorphism h_x: Tₙ → k(x), f ↦ f(x), it is clear that 𝔪_x = ker h_x is a maximal ideal in Tₙ. Thus,
there is a canonical map τ: Bⁿ(k_a) → Max Tₙ, x ↦ 𝔪_x, […]"

**Proposition 1 (7.1.1/1).** The map τ: Bⁿ(k_a) → Max Tₙ is surjective and has finite fibres. Let
x, y ∈ Bⁿ(k_a). Then τ(x) = τ(y) if and only if there is a γ ∈ Γ = Gal(k_a/k) such that γ(x) = y.
Hence τ induces a bijection Bⁿ(k_a)/Γ → Max Tₙ. In particular, if k is algebraically closed, τ
itself is bijective.

*Proof (first part).* First we verify the surjectivity of τ. Let 𝔪 ∈ Max Tₙ be a maximal ideal.
Then Tₙ/𝔪 is finite algebraic over k. Hence there is a continuous embedding Tₙ/𝔪 ↪ k_a, which gives
rise to a continuous map φ: Tₙ → k_a with kernel 𝔪. If x₁, …, xₙ denote the images of the
indeterminates of Tₙ via φ, then, by continuity, φ coincides with h_x: Tₙ → k_a, where
x = (x₁, …, xₙ). Therefore, τ(x) = ker h_x = 𝔪, and consequently, τ must be surjective. […]

**Lemma 2 (7.1.1/2), p. 261.** Let 𝔪 ⊂ Tₙ = k⟨ξ⟩ be a maximal ideal and let 𝔪' := 𝔪 ∩ k[ξ]. Then 𝔪'
is maximal in k[ξ] and 𝔪 = 𝔪'k⟨ξ⟩. Moreover, the injection k[ξ] ↪ k⟨ξ⟩ induces a bijection
k[ξ]/𝔪' ⥲ k⟨ξ⟩/𝔪.

(Proof uses 𝔪 = 𝔪_x, the density of k[ξ] in k⟨ξ⟩, and Proposition 2.3.3/4.)

**Proposition 3 (7.1.1/3).** Let 𝔪 ⊂ Tₙ = k⟨ξ⟩ be a maximal ideal. Then there are polynomials
pᵢ ∈ k[ξ₁, …, ξᵢ] which are monic in ξᵢ, i = 1, …, n, such that the ideals 𝔪' := 𝔪 ∩ k[ξ] and 𝔪 are
generated by p₁, …, pₙ. If, in addition, k is algebraically closed, one can take pᵢ = ξᵢ − xᵢ where
x = (x₁, …, xₙ) ∈ Bⁿ(k) is the point corresponding to 𝔪 (i.e., such that 𝔪 = 𝔪_x).

*Proof.* Choose a point x = (x₁, …, xₙ) ∈ Bⁿ(k_a) such that 𝔪 = 𝔪_x and, for i = 1, …, n, let
p̄ᵢ ∈ k(x₁, …, x_{i−1})[ξᵢ] denote the minimal polynomial of xᵢ over k(x₁, …, x_{i−1}). If
pᵢ ∈ k[ξ₁, …, ξᵢ] is a polynomial monic in ξᵢ and representing p̄ᵢ with respect to the canonical
projection k[ξ₁, …, ξᵢ] → k(x₁, …, x_{i−1})[ξᵢ], then, since all these polynomials vanish on x, we
have p₁, …, pₙ ∈ 𝔪'. Now, by induction, one easily shows that k[ξ₁, …, ξₙ]/(p₁, …, pₙ) = k(x). Thus,
p₁, …, pₙ generate the maximal ideal 𝔪' in k[ξ] and, by Lemma 2, they also generate the maximal
ideal 𝔪 in k⟨ξ⟩. […] ∎

**Board note.** 7.1.1/3 rests on 7.1.1/1, whose surjectivity proof needs "Tₙ/𝔪 is finite algebraic
over k" (Corollary 6.1.2/3, Noether normalisation) and the continuity of the embedding. Both are
Layer 1 (§1.2) and Layer 3 (§3.1) of the roadmap. Hence BGR's own proof of `dim T_d ≤ d` in the
Remark of 6.1.2 is not available in Layer 0.
