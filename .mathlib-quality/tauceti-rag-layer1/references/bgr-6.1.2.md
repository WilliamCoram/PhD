## 6.1.2 Noether normalization

"By definition each A ∈ 𝔄 is the residue algebra of a free algebra Tₙ. In this section, we prove
that, on the other hand, each A ∈ 𝔄 contains a free algebra T_d as subalgebra — more precisely,
that each A ∈ 𝔄 is a finite overalgebra of a free algebra T_d.
Recall that a ring homomorphism ϱ: R → S is called *integral* if S is integral over the subring
ϱ(R). We will see later that all integral homomorphisms of k-affinoid algebras are already finite,
but for the time being we are not yet able to use this result."

**Theorem 1 (6.1.2/1).** (i) Let A be a non-zero k-affinoid algebra. For every finite (resp.
integral) homomorphism α: Tₙ → A, there exist a chart {X₁, …, Xₙ} of Tₙ and an integer d ≥ 0 such
that α | k⟨X₁, …, X_d⟩ is finite (resp. integral) and injective.
(ii) Let φ: B → A be a finite (resp. integral) homomorphism between non-zero k-affinoid algebras.
Then there exists a homomorphism ψ: T_d → B for some d ≥ 0 such that φ ∘ ψ: T_d → B → A is finite
(resp. integral) and injective.

*Proof.* First let us reduce the second statement to the first one. By choosing an epimorphism
α: Tₙ → B and applying the first statement to the map φ ∘ α: Tₙ → A, one gets a subalgebra
T_d ⊂ Tₙ such that (φ ∘ α) | T_d: T_d → A is finite (resp. integral) and injective. Then
ψ := α | T_d has the required properties.
Now let us prove the first assertion. We proceed by induction on n. The case n = 0 is trivial. Let
n ≥ 1. If ker α = 0, there is nothing to prove. Otherwise we can find a chart {X₁, …, Xₙ} of Tₙ and
a Weierstrass polynomial

  ω ∈ T_{n−1}[Xₙ],  T_{n−1} = k⟨X₁, …, X_{n−1}⟩,

such that ω ∈ ker α. Then α induces a finite (resp. integral) homomorphism ᾱ: Tₙ/ωTₙ → A. By the
WEIERSTRASS Finiteness Theorem 5.2.3/4, the natural injection T_{n−1} → Tₙ induces a finite
monomorphism β: T_{n−1} → Tₙ/ωTₙ. Obviously, ᾱ ∘ β is finite (resp. integral), and one has
ᾱ ∘ β = α | k⟨X₁, …, X_{n−1}⟩. Applying the induction hypothesis to T_{n−1} and ᾱ ∘ β, we get the
theorem. ∎

"As a special consequence of the theorem, one obtains the so-called NOETHER Normalization Lemma (in
analogy to the corresponding theorem for finitely generated k-algebras)."

**Corollary 2 (6.1.2/2).** For every k-affinoid algebra A ≠ 0, there exists a finite monomorphism
φ: T_d → A for some d ≥ 0.

**Remark (p. 228).** Using some facts about Krull dimensions of rings, one can show that the integer
d above is uniquely determined by the algebra A. Namely, dim A = dim T_d (for example, use NAGATA
[28] Corollary 10.10), and dim T_d = d. The latter assertion is easily verified. Namely, the chain
of prime ideals

  0 ⊂ (X₁) ⊂ (X₁, X₂) ⊂ … ⊂ (X₁, …, X_d)

shows that dim T_d ≥ d. Since each maximal ideal in T_d can be generated by d elements (Proposition
7.1.1/3), we must have dim T_d = d.

**Corollary 3 (6.1.2/3).** Let A be a k-affinoid algebra; let 𝔮 be an ideal in A such that its
nilradical rad 𝔮 is a maximal ideal in A. Then A/𝔮 is finite over k.

*Proof.* By the theorem, there exists a finite monomorphism φ: T_d → A/𝔮 for some d ≥ 0. We claim
d = 0, i.e., T_d = k. The composition of φ with the canonical epimorphism ϱ: A/𝔮 → A/rad 𝔮 is
finite and injective (because T_d is reduced). The ideal rad 𝔮 being maximal, we see that T_d has a
finite extension which is a field. But then T_d must itself be a field so that d = 0 and T_d = k. ∎

"Another consequence of Theorem 1 is"

**Proposition 4 (6.1.2/4).** Every k-affinoid algebra A which is an integral domain is Japanese.

*Proof.* Let A' be an integral extension of A such that its field of fractions Q(A') is a finite
extension of Q(A). We have to show A' is a finite A-module. By the theorem, there is a normalization
map φ: T_d → A for a suitable d ≥ 0. Then A' is an integral extension of T_d, and Q(A') is finite
over Q(T_d). Since T_d is Japanese by Theorem 5.3.1/3, we see that A' is a finite T_d-module and a
fortiori a finite A-module. ∎

## 6.1.3 Continuity of homomorphisms (p. 229, start)

"For each k-affinoid algebra B ∈ 𝔄, the set 𝔅 := {𝔪^ν; 𝔪 maximal ideal in B, ν ∈ ℕ} fulfills
conditions (i) and (ii) of Proposition 3.7.5/2. Namely, (i) dim_k B/𝔟 < ∞ for each 𝔟 ∈ 𝔅,
(ii) ⋂_{𝔟 ∈ 𝔅} 𝔟 = (0)."

*Proof.* We have dim_k B/𝔟 < ∞ for all 𝔟 ∈ 𝔅 by Corollary 6.1.2/3. In order to show ⋂ 𝔟 = (0), take
any f ∈ B such that f ∈ ⋂_{ν ≥ 1} 𝔪^ν for all maximal ideals 𝔪 ⊂ B. KRULL's Intersection Theorem
implies that for each 𝔪 there is an element m ∈ 𝔪 such that (1 − m) f = 0. Hence the annihilator of
f is contained in no maximal ideal in B. Therefore, f = 0 and (ii) holds. ∎

**Theorem 1 (6.1.3/1).** Each k-algebra homomorphism of a Noetherian k-Banach algebra into a
k-affinoid algebra is continuous.

**Proposition 2 (6.1.3/2).** If A is k-affinoid, then any k-Banach algebra topology on the k-algebra
A coincides with the k-affinoid topology of A.
